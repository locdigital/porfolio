## Re-downloading Assets

```bash
node scripts/download-dock-assets.mjs
```

## Customization

Edit `src/components/dock/dock.config.ts` to add, remove, reorder, or disable applications, or pass custom props to `<Dock />`:

```tsx
<Dock
  position="left" // or "bottom"
  motion={{ maxScale: 1.5, influenceRadius: 150 }}
  apps={customApps}
/>
```
